## 5Mbps 是这条线的天花板，也是它卖 $24.99 的理由

5Mbps 换算下来约 625KB/s 的峰值吞吐。一个优化到 1.5MB 的页面，纯带宽层面要两秒多才传完一份，十个人同时打开就是二十多秒。这还没算 TLS 握手、TTFB 和回源。

所以台湾线这档配置的真实使用场景很窄：日访问几百到几千 PV 的企业展示页、只返回 JSON 的 API、定时上报的探针、内部管理后台、低流量的个人博客。这些场景里 CPU 和内存几乎不动，带宽也够。反过来，任何以"传输体积"为核心的业务都不合适：图片站、视频、软件下载、CDN 回源、大促期间的电商详情页。

台湾机房的优势在延迟，不在带宽。台湾本地访问通常在个位数毫秒，到大陆沿海城市的跨境延迟也在几十毫秒量级，这个数字各家厂商都在宣传，但缺少统一测试方法，只能作为方向性参考。延迟低和带宽大是两件事，5Mbps 的方案延迟再低，也传不快一个 20MB 的安装包。

## 流量制还是带宽制：一条起价差三倍的分界线

台湾云主机有两种计费模式，选错模式比选错配置更浪费钱。

流量制给固定月流量，超出按 GB 计费或限速。天空數位的流量制起价 NT$1,270/月，入门含 100Mbps 网络和 300GB 流量。适合访问量起伏大、多数时间闲着、偶尔冲一波的站点。

带宽制按所选带宽给不限流量。天空數位的带宽制起价 NT$4,340/月，是流量制起价的三倍多。适合持续高吞吐的业务：视频、直播、CDN 回源、大文件分发。

LightLayer 台湾线属于带宽制思路，5Mbps 配不限流量。这个组合对小站友好，因为不用担心流量超标被扣费；代价是带宽上限锁死在 5Mbps，想快只能换方案。

"不限流量"这四个字要看清楚。天空數位的不限流量是不限制传输量，梦飞 idc 的"无限流量"后面跟着一条"过量降速至 2Mbps"，两种写法含义完全不同。签约前确认限速阈值写在哪一条。

## 便宜套餐省的是存储和流量，不是 CPU

低价位台湾云主机的配置差异，几乎都落在硬盘和流量上，CPU 反而都给得差不多。

对比 LightLayer 台湾线的 1 核 / 1GB / 50GB SSD / 5Mbps 不限流量，可以看到三种不同的取舍：梦飞把成本压在 25GB 硬盘和 1TB 流量上，天下数据压在 30GB 硬盘上但给了 1G 带宽，LightLayer 给了 50GB 硬盘和不限流量但带宽只有 5Mbps。

所以"哪家便宜"这个问题没有统一答案，得先确定你的瓶颈在哪。硬盘装得下、流量不超、带宽够用，三个条件里哪个先破，就照那个选。

## 下单前常问的几个问题

**大陆访问延迟到底多少？**

公开渠道没有 LightLayer 台湾线的延迟数据。第三方测评里出现的 35ms、40–60ms、低于 30ms 分属不同商家，测试方法不明且互相矛盾，只能当方向参考。延迟和带宽要分开看，5Mbps 的方案延迟再低也传不快大文件。要判断实际体验，先买最短周期，用目标地区的机器做 ping 和下载测试。

**要不要备案？**

台湾机房不涉及大陆的 ICP 备案流程，这一点多家厂商都在产品页写过。但你的域名、业务面向、支付通道是否涉及其他资质要求，取决于具体经营内容，不是换个机房就能绕开的事。

**能装宝塔、1Panel 这类面板吗？**

LightLayer 使用 KVM 虚拟化，第三方资料显示提供 AMD EPYC 处理器与 NVMe 存储，用户拿到的是独立操作系统环境。按这个架构，安装宝塔、1Panel、LAMP/LNMP 都没有技术障碍，1GB 内存跑面板加一个轻量站点属于刚好够用的水平，装完剩不下太多余量。

**IP 被封了怎么办？**

公开资料里没有 LightLayer 关于换 IP 的政策说明，是否收费、是否支持保留实例更换主 IP 都查不到。这类条款必须下单前问客服，别默认能免费换。

**能不能先试用？**

没有查到免费试用的公开说明。按退款政策"仅提供商责任"的口径，试用成本等于一个最短计费周期的费用。
